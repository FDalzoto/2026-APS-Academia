**Figura 3 – Diagrama de atividades de Caso de atividade**

![Diagrama de atividades](../diagramas/Diagrama_de_atividade-Página-2.drawio.png.png)

Fonte: Autoria própria (2026).

O diagrama apresenta o processo de registro de pagamento, dividido em duas raias: Atendente e Sistema. O atendente identifica o aluno e informa os dados do pagamento, enquanto o sistema apresenta as mensalidades e verifica as informações. Se houver mais de uma mensalidade pendente, o atendente seleciona uma. Depois, o sistema verifica se os dados são válidos: se sim, registra e confirma o pagamento; se não, informa o erro. Os dois finais representam o sucesso ou o encerramento sem registro do pagamento.
